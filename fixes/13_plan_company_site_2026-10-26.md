## 4. مكان الكود وطريقة البناء
```
company-site/
  content.json        # كل النصوص والأرقام والروابط بلغتين — التعديل هنا فقط
  build.py            # Python قياسي بلا مكتبات: يولّد dist/ من content.json والقالب
  templates/page.html
  assets/ (css, js, images, logos, fonts)
  dist/               # الناتج المرفوع إلى public_html (متتبَّع في git كالمتجر)
```
- `python3 company-site/build.py` يولّد `dist/index.html` و`dist/en/index.html` وينسخ الأصول.
- بلا Node ولا npm لهذا الموقع؛ الحجم المستهدف أقل من 1.5 ميغابايت بالصور.
- الأداء: صور مضغوطة بأحجام مناسبة و`loading="lazy"`، خطوط محلية، لا مكتبات خارجية، لا خطوط من Google.
