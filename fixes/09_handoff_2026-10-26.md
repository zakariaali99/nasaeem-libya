## 1. المشروع باختصار

متجر عطور ليبي: عطور، وزيوت عطرية، وأطقم هدايا، بالجملة والقطاعي. الدفع عند الاستلام أو بتحويل مصرفي. التوصيل يُتفق عليه مع العميل بالهاتف عند تأكيد الطلب.

| الجزء | المكان | التقنية |
|---|---|---|
| الخادم | `store-app/backend` | Django + DRF. البايثون: `.venv/bin/python` |
| الواجهة | `store-app/frontend` | React + Vite + TypeScript + React Query + Tailwind |
| البناء المرفوع | `store-app/backend/dist` | **يُرفع مع الكود** (نسخة من `frontend/dist`) |
| الخطط والتوثيق | `fixes/` | خطط مرقّمة 00–08، وهذا الملف 09 |
| أفكار مستقبلية | `next in line/` | 12 ملفاً للتوسع، ليست ضمن العمل الحالي |

### البيئات
- **الموقع الحي:**
  - cPanel مع Passenger، وقاعدة بيانات **SQLite**.
  - **المسار `/api/` وحده يصل إلى Django.** الواجهة ملفات ثابتة في `~/shop`.
  - لا يوجد `rsync` على الخادم، فالنسخ يكون بـ `tar`.
- **محلياً:**
  - قاعدة البيانات Postgres.
  - خادم التجربة على المنفذ **8001**: إعداد `django-8001` في `.claude/launch.json`. المنفذ 8000 لمشروع آخر.

### الأوامر
```bash
# الخادم: كل الاختبارات
cd store-app/backend && .venv/bin/python -m pytest -q

# الواجهة: الأنواع والاختبارات والبناء
cd store-app/frontend && npm run typecheck && npx vitest run && npm run build

# نسخ البناء إلى الخادم (يُرفع مع الكود)
cd store-app && rsync -a --delete frontend/dist/ backend/dist/
```

### الرفع على الخادم الحي (يقوم به صاحب المتجر)
1. نسخة احتياطية من `db.sqlite3`.
2. `git pull`
3. `python manage.py migrate`، إن كان في المرحلة ترحيل.
4. `touch tmp/restart.txt`
5. نسخ `dist` إلى `~/shop` بـ `tar`، مع استثناء `.htaccess` و`media`.

بعد كل مرحلة، أعطِ صاحب المتجر هذه الخطوات، واذكر اسم كل ترحيل جديد.

## 2. قواعد ثابتة (لا استثناء)

1. **ابحث عن السجل بالمعرّف `id`، لا بالـ slug**، في كل تعديل أو حذف أو مسار في لوحة التحكم أو نداء من الواجهة. الـ slug للروابط العامة فقط.
2. **الخادم الحي SQLite:**
   - لا كود خاص بـ Postgres.
   - الاختبارات المحلية على Postgres قد تنجح بينما الموقع الحي يتعطل.
3. **لا تشغّل `makemigrations storefront` أبداً.**
   - على الخادم الحي ملف غير متتبَّع اسمه `storefront/0003_alter_widget_type.py`.
   - اكتب الترحيل المطلوب يدوياً، لتطبيق محدد.
4. **الميزة الموقوفة تُخفى ولا تُحذف**، مثل رسوم التوصيل وتغليف الهدايا.
5. **لا OTP ولا رسائل SMS.**
   - العميل يشتري بلا كلمة مرور، وطلباته محفوظة على جهازه.
   - كلمات المرور يضعها الموظفون.
6. **العمل على `main` مباشرة**: commit ثم push، بلا فروع ولا PR.
   - آخر سطر في رسالة كل commit: سطر `Co-Authored-By` للوكيل.
7. **لا تستخدم كلمات مرور أو رموز دخول نيابة عن صاحب المتجر.**
   - لاختبار لوحة التحكم في المتصفح، يسجّل هو الدخول.
8. **على الخادم:** لا تحذف شيئاً في `public_html`، ولا نسخة يناير 2025 الاحتياطية (`tar.gz`).
9. **كل تغيير يُجرَّب في المتصفح المدمج** بالعرضين (حاسوب وهاتف)، وباللغتين (`/` و`/en/`). الاختبارات وحدها لا تكفي.
10. **بيانات التجربة المحلية تُحذف بعد الاختبار بنداً بنداً.** لا تحذف بالجملة.
11. **الكود يشبه ما حوله:** نفس كثافة التعليقات والتسمية والأسلوب.
12. **الإنجليزية للمتجر فقط.** لوحة التحكم عربية.

## 6. ما ينتظر التحقق من المرحلة و-2

شاشات لوحة التحكم الجديدة **لم تُجرَّب في المتصفح**، لأنها تحتاج تسجيل دخول. الكود سليم، والحفظ مغطّى باختبارات. جرّبها حين يسجّل صاحب المتجر الدخول:
- قسم «النسخة الإنجليزية (اختياري)» في نموذج المنتج: الاسم، والوصف، وSEO، والعائلة، والمنشأ، والنفحات مفصولة بفاصلة.
- حقلا «الاسم بالإنجليزية» و«الوصف بالإنجليزية» في التصنيفات والمجموعات.
- حقل الاسم الإنجليزي لكل مدينة ومنطقة في صفحة المدن.
- حقل «بالإنجليزية» تحت كل سطر في «نصوص المتجر»، ويُحفظ بمفتاح `en:<key>`.
- مفتاح «النصوص: عربي / English» في محرر الواجهة، ويكتب في `<key>_en`.
- علامة «ينقصه الإنجليزي» في قائمة المنتجات.

## 7. كيف تعمل الإنجليزية (مرجع سريع)

- **اللغة من الرابط:** `/en/...` إنجليزي، والباقي عربي.
  - لا تُترجَم `/admin` ولا `/api` ولا `/media`.
  - محركات البحث لا تُحوَّل أبداً.
- **أول زيارة:**
  - الاختيار المحفوظ (`localStorage` `store_lang`) يغلب لغة الجهاز.
  - بلا اختيار محفوظ: جهاز غير عربي يدخل رابطاً عربياً يُحوَّل إلى `/en/`.
- **أدوات الواجهة:** `src/lib/i18n.ts`، وفيه `t` و`tCount` و`localePath` و`stripLang` و`isEnglish`.
  - الرسائل في `src/locales/ar.ts` و`en.ts`.
  - روابط الواجهة تمر عبر `src/lib/i18nRouter.tsx`، فتُضاف `/en` تلقائياً.
- **المحتوى من الخادم:**
  - كل نداء من صفحة `/en/` يضيف `?lang=en` (في `src/lib/api.ts`).
  - الخادم: `apps/core/language.py`، وفيه `wants_english` و`EnglishFieldsMixin` و`localise_widget` و`lang_key`/`forget` للذاكرة المؤقتة.
  - لكل حقل قابل للترجمة توأم `_en`. **التوأم الفارغ يُظهر العربي.**
  - المقاسات تُترجم تلقائياً («100 مل» تظهر "100 ml").
- **ذاكرة React Query لكل لغة:** `queryKeyHashFn` في `App.tsx`.
- **نصوص المتجر:** `src/lib/siteText.ts`. الصيغة الإنجليزية في `texts['en:<key>']`. السطر المخفي بالعربي مخفي باللغتين.
- **رسائل الخادم بالإنجليزية:** gettext. ملف `.mo` المترجَم يُرفع مع الكود، فالخادم بلا أدوات gettext.
